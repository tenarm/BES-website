# Video Asset: App Constellation — Connected Modules

**Section:** App Catalogue ("18 apps, one connected spine")
**Replaces:** CSS orbital constellation with rotating nodes
**Duration:** 15–20 seconds, looping
**Dimensions:** 800×800 (1:1 square), transparent background preferred
**Type:** Motion graphics (After Effects / Rive / Lottie)

## What to Show

An elegant motion graphic showing how the 18 apps connect through a central core:

### Animation Flow

1. **Core pulse** (0s–2s)
   - TenArm starburst logo at center glows and pulses
   - "BES CORE" label fades in below

2. **Inner ring appears** (2s–6s)
   - 4 primary apps materialize around the core: Sales, Finance, Inventory, CRM
   - Each appears with its icon and label
   - Subtle connection lines draw from core to each node
   - Data particles flow along the connection lines

3. **Outer ring expands** (6s–10s)
   - 8 secondary apps appear in an outer ring: HR, Payroll, Manufacturing, Maintenance, Projects, Service, Logistics, Assets
   - Outer connection lines draw
   - More data particles flowing between nodes

4. **Cross-connections light up** (10s–14s)
   - A few cross-module connections illuminate (Sales → Inventory → Finance)
   - Shows the integrated data flow
   - Brief highlight pulse on the connected path

5. **Steady state loop** (14s+)
   - All nodes present, gentle floating motion
   - Data particles continuously flowing
   - Subtle glow pulsing on the core

## Visual Direction

- **Dark background** (#00091a navy or transparent) — this section is on dark
- **Maroon (#a60212) and gold (#a07a3f) accent colors** for nodes and connections
- **White/light text** for labels
- **Clean, geometric** — No 3D, no drop shadows. Flat with subtle glow.
- **Data particles** — Tiny dots (2-3px) flowing along connection lines in brand colors

## Delivery Format

- **Preferred:** Lottie JSON (via LottieFiles) for web-native rendering with small file size
- **Alternative:** WebM video with alpha channel (transparent background)
- **Fallback:** MP4 with dark background baked in

## Usage Notes

- Embed using `<lottie-player>` or `<video>` depending on format
- Keep the current CSS orbital as fallback for browsers without video support
- Consider interactive hover states if using Lottie (highlight node on hover)
